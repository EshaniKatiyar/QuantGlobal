## ASSESSMENT
Q001: 
A trader observes that a stock price is moving in an oscillating pattern between two levels (let's say $50 and $60). The trader wants to create a trading strategy based on this observation. What type of trading strategy would you recommend, and why?

Topic: Trading Strategy Development

Answer: A simple Moving Average Crossover strategy would be suitable for this scenario. By using a short-term moving average (e.g., 20-period) and a long-term moving average (e.g., 50-period), the trader can identify when the price is likely to cross over from one trend to another, providing an opportunity to buy or sell.

Q002: 
Suppose you have a portfolio of stocks with their respective daily returns. You want to calculate the Sharpe Ratio for this portfolio. What formula would you use, and what assumptions would you make?

Topic: Portfolio Analysis

Answer: The Sharpe Ratio formula is (R_p - R_f) / σ_p, where R_p is the portfolio return, R_f is the risk-free rate, and σ_p is the portfolio standard deviation. I would assume that the risk-free rate is a constant value (e.g., 2% for a US Treasury bond), and that the portfolio returns are calculated using daily returns.

Q003: 
A trading platform provides you with historical price data for a particular stock. You want to create a backtesting framework to evaluate the performance of a trading strategy. Which Python library would you use, and why?

Topic: Backtesting Frameworks

Answer: I would use the Zipline library, as it is well-suited for backtesting algorithmic trading strategies. Zipline provides an easy-to-use API for defining trading strategies, as well as built-in support for risk management and performance metrics.
