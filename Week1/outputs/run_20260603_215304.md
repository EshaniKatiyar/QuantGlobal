Q1: A trader observes that the daily returns of a stock are normally distributed with a mean of 0.05 and a standard deviation of 0.1. If the trader wants to know the probability that the return on a given day will be greater than 0.08, what is the correct answer?

Topic: Probability Distribution

Answer: The correct answer is 0.5.

Explanation: Since the daily returns are normally distributed with a mean of 0.05 and a standard deviation of 0.1, we can use the z-score formula to calculate the probability. The z-score is given by (X - μ) / σ, where X is the value we're interested in (0.08), μ is the mean (0.05), and σ is the standard deviation (0.1). Plugging in these values, we get (0.08 - 0.05) / 0.1 = 0.3. Using a standard normal distribution table or calculator, we find that P(Z > 0.3) = 0.5.

Q2: A portfolio manager wants to maximize the Sharpe ratio of her portfolio. The portfolio's expected return is 8% and its volatility is 10%. If she can add either a stock with an expected return of 12% and a standard deviation of 15%, or a bond with an expected return of 4% and a standard deviation of 2%, which option would result in the highest Sharpe ratio?

Topic: Portfolio Optimization

Answer: The correct answer is to add the stock.

Explanation: The Sharpe ratio is given by (E(R) - Rf) / σ, where E(R) is the expected return, Rf is the risk-free rate, and σ is the volatility. In this case, the portfolio's expected return is 8% and its volatility is 10%. If we add a stock with an expected return of 12% and a standard deviation of 15%, the new expected return would be 20% (8% + 12%) and the new volatility would be 17.2% (10% + 7.2%). The Sharpe ratio would then be (0.20 - 0.08) / 0.172 = 0.87, which is higher than adding a bond with an expected return of 4% and a standard deviation of 2%, resulting in a Sharpe ratio of (0.04 - 0.08) / 0.02 = -0.20.

Q3: A trader observes that the daily returns of a stock are not normally distributed, but rather follow a power-law distribution with a parameter of 1.5. If the trader wants to know the probability that the return on a given day will be greater than 2 standard deviations above the mean, what is the correct answer?

Topic: Non-Parametric Distribution

Answer: The correct answer is approximately 0.001.

Explanation: Since the daily returns follow a power-law distribution with a parameter of 1.5, we can use the cumulative distribution function (CDF) to calculate the probability. The CDF for a power-law distribution is given by P(X < x) = (x / μ)^α, where α is the parameter and μ is the mean. We want to find P(X > 2μ + σ), which is equivalent to 1 - P(X ≤ 2μ + σ). Plugging in the values, we get 1 - ((2μ + σ) / μ)^1.5. Since the standard deviation is not given, we assume it's equal to the mean (which is a common assumption for power-law distributions). Using numerical methods or software, we find that P(X > 2μ + σ) ≈ 0.001.
