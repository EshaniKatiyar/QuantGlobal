Q[1]: A trader observes the following closing prices of XYZ Inc. stock over the past year:
 
     2022-01-01: $50
     2022-02-01: $52
     2022-03-01: $55
     2022-04-01: $58
     2022-05-01: $60
     2022-06-01: $62
     2022-07-01: $65
     2022-08-01: $68
     2022-09-01: $70
     2022-10-01: $72
     2022-11-01: $75
     2022-12-01: $78

What is the average daily return of this stock over the past year?

Topic: Time Series Analysis and Calculating Returns

Answer: The average daily return can be calculated by taking the total return over the period (78 - 50 = 28) and dividing it by the number of days in the period (31). 

Average Daily Return = (Total Return / Number of Days)
= (28 / 31)
≈ 0.903

Q[2]: A portfolio manager wants to allocate $100,000 among two assets: XYZ Inc. stock with a historical return of 10% and YZ Corp. stock with a historical return of 8%. The portfolio manager also wants the overall portfolio return to be 9%. What is the optimal allocation between the two stocks?

Topic: Portfolio Optimization and Markowitz Model

Answer: To solve this problem, we can use the Markowitz model, which aims to maximize the Sharpe ratio. However, since the problem doesn't specify any constraints on the weights, we will assume that the weights are within the bounds of 0 and 1.

Let's denote the weight of XYZ Inc. stock as x and the weight of YZ Corp. stock as y. We can set up the following equation to represent the overall portfolio return:

10x + 8y = 9

We also know that the weights must sum to 1:

x + y = 1

Solving these two equations simultaneously, we get:

x = 0.5
y = 0.5

Therefore, the optimal allocation between the two stocks is 50% each.

     Day 10: 0.02
     Day 11: -0.01
     Day 12: 0.03

What is the average daily return of this trading strategy over the past month?

Topic: Time Series Analysis and Calculating Returns

Answer: The average daily return can be calculated by taking the total return over the period (0.03) and dividing it by the number of days in the period (12). 

Average Daily Return = (Total Return / Number of Days)
